# Courtly Booking — starter-проєкт для ЛР №10

Каталог майданчиків вигаданого сервісу Courtly: пошук за містом і видом спорту,
вибір дати, картки майданчиків, діалог бронювання та список бронювань. Це
**навчальний starter**: код написано так, ніби його швидко зібрали під дедлайн.
На перший погляд застосунок працює, але містить JavaScript-дефекти — знайти,
довести й виправити їх і є завданням лабораторної роботи.

Опис завдання та очікувана поведінка застосунку:
<https://denysmatsevych.github.io/web-development-2026/web-development/labs/lab-10/> і
<https://denysmatsevych.github.io/web-development-2026/web-development/labs/lab-10/task/>.

## Склад

```text
index.html          сторінка застосунку
css/tokens.css      design tokens Courtly (ті самі, що в ЛР-7)
css/styles.css      стилі
data/venues.json    дані майданчиків
js/main.js          точка входу: підключає обробники подій
js/api.js           fetchVenues() — імітація запиту до сервера
js/render.js        картки та результати пошуку
js/booking.js       діалог бронювання та «Мої бронювання»
js/format.js        форматування ціни та дати
img/                логотип, favicon, зображення майданчиків
.nojekyll           щоб GitHub Pages не пропускав файли з підкресленням
```

Збірки немає: це статичні файли, які віддаються як є. JavaScript підключено як
ES-модулі (`<script type="module">`).

## Як запустити локально

Відкривати `index.html` через `file://` **не** можна: браузер не завантажить
ES-модулі та не виконає `fetch()` для `data/venues.json`. Підніміть локальний
сервер у корені проєкту — наприклад, Live Server у VS Code або:

```bash
# Node
npx serve .

# або Python
python -m http.server 8000
```

і відкрийте адресу, яку покаже сервер.

## Як задеплоїти

Вміст цієї теки можна покласти або в **окремий репозиторій**, або у теку
`lab-10/` спільного репозиторію з лабораторними. Усі шляхи в проєкті відносні,
тому він працює і з кореня origin, і з підтеки.

### GitHub Pages

1. Завантажте файли в репозиторій.
2. Settings → Pages → Source: *Deploy from a branch*, гілка `main`, тека `/`.
3. Сторінка з'явиться за адресою `https://<username>.github.io/<repository>/`
   (або `…/<repository>/lab-10/`, якщо проєкт у вкладеній теці).

Якщо проєкт у вкладеній теці, скопіюйте `.nojekyll` ще й у корінь репозиторію:
GitHub Pages шукає цей файл у корені опублікованої гілки.

### Vercel

1. [vercel.com](https://vercel.com) → Add New → Project → імпорт репозиторію.
2. Framework Preset: **Other**. Build Command і Output Directory залиште
   порожніми — збирати нічого не потрібно.
3. Якщо проєкт лежить у вкладеній теці — **Root Directory → `lab-10`**.

## Обмеження

- Жодного збірника, бібліотек чи фреймворків — тільки HTML, CSS і JavaScript.
- Переписувати застосунок не потрібно: структура модулів і зовнішній вигляд
  мають залишитися такими ж.
- Courtly — вигаданий сервіс. Назви майданчиків, ціни й контакти — теж.
